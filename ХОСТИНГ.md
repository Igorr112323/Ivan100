# Хостинг АКВАЧЕК: что арендовать и как разместить

Дата: 02.11.2026. Ветка `arena/3e1e66ac-ivan100`.
Разбираем задачу: сайт доступен всем, жюри сканирует QR и попадает на страницу,
держит минимум 10 одновременных подключений, без лимита на подключения с одного IP.

## 0. Что именно надо размещать (проверено по коммиту `e4d2754`)

| Факт | Значение |
|---|---|
| Продукт | `dist/akvachek.html` — **723 577 байт (0,69 МБ)**, один файл |
| Внешние запросы | **ноль**: ни `http://`, ни `https://` внутри файла; данные, шрифты и карта вшиты |
| Серверная логика | не нужна. `Dockerfile` / `docker-compose.yml` в проекте — это расчётный API (uvicorn), готовый экран от него не зависит |
| Остальные файлы | `index.html` (редирект на экран), `questions.html`, 2 PDF, 5 PNG = ещё ~3,8 МБ |
| QR сейчас | `dist/qr.png` кодирует `https://cdn.jsdelivr.net/gh/Igorr112323/Ivan100@bd402edc3abfe655dfd4d384da2e9ce45bac3daa/dist/akvachek.html` (адрес из `web/site_url.py`, перевыпущен коммитом `e4d2754`) |
| GitHub Pages | не включён: `GET /repos/Igorr112323/Ivan100/pages` → 404; включать вручную в Settings → Pages |
| Проверка jsDelivr | из песочницы недоступен (разрешены только github.com / api.github.com), **ссылку надо открыть глазами с телефона** |

**Арифметика нагрузки:** 10 человек × 0,69 МБ = **~7 МБ суммарно**. Это не нагрузка
ни для CDN, ни для любого VPS. nginx на 512 МБ ОЗУ держит тысячи таких соединений.
10 подключений из-под одного NAT (весь зал на одном Wi-Fi) — обычная ситуация,
ни один нормальный хостинг на таких объёмах не блокирует.

---

## 1. Рекомендация: сервер арендовать НЕ надо

Сайт статический, публичный, уже лежит на jsDelivr, QR уже указывает туда.
На jsDelivr и GitHub Pages нет лимита «10 соединений с одного IP», HTTPS есть,
платить не за что, администрировать нечего.

Что сделать за 5 минут, в этом порядке:

1. **Открыть текущую ссылку с телефона по мобильному интернету** (выключить Wi-Fi),
   лучше с двух разных операторов:
   `https://cdn.jsdelivr.net/gh/Igorr112323/Ivan100@bd402edc3abfe655dfd4d384da2e9ce45bac3daa/dist/akvachek.html`
   Если открылась карта 51 чека — задача уже решена, ничего арендовать не надо.
2. **Отсканировать напечатанный QR** тем же телефоном — убедиться, что он ведёт туда же.
3. **Включить GitHub Pages как запасной адрес** (бесплатно): Settings → Pages →
   Deploy from a branch → ветка `arena/25308257-ivan100`, папка `/dist` → Save.
   Через 1–2 минуты появится `https://igorr112323.github.io/Ivan100/akvachek.html`.
   Записать его в `ВЫДАЧА.md` вторым адресом. Токен агента Pages включить не может (403),
   это делается руками в браузере.
4. Проверить deep link `?limit=70`, PDF ведомости и страницу пяти вопросов.

Минус этого пути: зависимость от зарубежного CDN. В России он обычно доступен,
но если на площадке его режут — нужен вариант 2.

## 2. Если VPS арендовать обязательно (требование конкурса / нужен адрес в РФ)

### Какой тариф брать

| Параметр | Что выбрать | Почему |
|---|---|---|
| Тариф | **самый младший**, `First 49 ₽` или `Start 69 ₽` | 10 подключений × 0,69 МБ не требуют ни 4 ГБ, ни 8 ГБ ОЗУ. Платить 159/239 ₽ не за что |
| ОС | **Ubuntu / Debian**, не Windows | Windows + IIS съест всю память младшего тарифа; nginx занимает ~10–30 МБ |
| Локация | 🇷🇺 Россия | жюри в Краснодаре, меньше зависимость от зарубежного канала |
| Срок | **с запасом**: день защиты + репетиция + 2–3 дня | На скриншоте выбран период «7 дней» — если защита позже, сервер исчезнет в самый день. Уточнить, это цена за 7 дней или за месяц |
| Публичный IPv4, порты 80/443 | убедиться, что входят и открыты | В скриншоте «Выделенный IP (65 ₽/мес)» — отдельная опция. Без белого IP и открытых портов QR не дойдёт |
| Резервные копии / NVMe | **не брать** | 4,5 МБ статики перезаливаются за минуту с любого компьютера |

У хостера стоит прямо спросить одним сообщением:
> Нужны ли ограничения на число одновременных соединений с одного IP и включён ли
> anti-DDoS с проверкой браузера (challenge)? Мне надо 10–20 заходов с одного NAT.

На 10 соединениях ни то, ни другое не срабатывает, но лучше узнать заранее.

### Какую ОС именно

| Выбор | Брать | Почему |
|---|---|---|
| Версия | **Ubuntu 22.04 LTS или 24.04 LTS** (оранжевая иконка), x86_64 | Под неё написаны все команды ниже (`apt`, `nginx`, `certbot`). LTS = поддержка 5 лет, не сломается за неделю |
| Альтернатива | **Debian 12/13**, если Ubuntu нет в списке | Тот же `apt`, ещё легче на 512 МБ ОЗУ. Инструкция подходит без изменений |
| Не брать | **Windows** | Ради одного HTML: 1–2 ГБ ОЗУ только на саму систему, RDP/Defender/активация, IIS или `python -m http.server` вместо nginx, лишние деньги и возня |
| Не брать | CentOS / RHEL-подобные / «синяя звёздочка» (rolling-сборки) | CentOS 7 умер в 2024-м, CentOS Stream — rolling; у них `dnf`, SELinux, `firewall-cmd`, другие пакеты. Наши команды не подойдут, а переписывать их за день до защиты некогда |
| Язык системы | **English** (RU тоже ок) | На кириллицу сайта не влияет: HTML в UTF-8. Английская локаль — меньше сюрпризов в логах nginx и certbot |
| Комплектация | **«чистая ОС», без панели и без GUI** | ISPmanager/cPanel/рабочий стол съедят память младшего тарифа; нам нужен только SSH и nginx |

Сам сайт — обычный HTML в браузере телефона, ему **всё равно**, какая ОС на сервере.
ОС важна только нам: чтобы за 10 минут выполнить команды из инструкции. Поэтому берите
то, под что она написана, — Ubuntu LTS.

После оплаты должны прийти **IP, логин `root` и пароль/SSH-ключ**. Проверьте сразу:
`ssh root@<IP>`. Если в тарифе обещают только RDP и никакого SSH — это Windows-тариф,
его брать не надо. На Windows-компьютере отдельный клиент не нужен: в PowerShell
уже встроены `ssh` и `scp`.

### Чек-лист формы заказа (по скрину rdp.onedash.ru, 02.11.2026)

| Поле на форме | Что поставить | Комментарий |
|---|---|---|
| Система | ✅ **Ubuntu 24** (уже выбрано) | Верно. Ubuntu 18/20 — устаревшие, 22 тоже LTS и подошла бы, но 24 — лучший выбор |
| Процессор | `Intel E5` (уже выбрано) | Нормально, AMD 4.5 GHz для статики не нужен |
| Локация | **🇷🇺 первый флаг** | На скрине активный флаг не различим. Жюри в Краснодаре — берите РФ: быстрее и без зарубежного канала |
| Язык системы | RU или EN | На кириллицу сайта не влияет |
| Выделенный IP (65 ₽/мес) | ✅ **включить** (уже включено) | Нужен белый IPv4 с открытыми 80/443. Это не лишняя опция |
| Резервные копии / Диск NVMe | ❌ выключить (уже выключено) | Верно: 4,5 МБ перезалить за минуту |
| Срок | ⚠️ **не «7 дней» впритык** | Сегодня 02.11.2026. Если защита позже 09.11, сервер исчезнет до неё. Возьмите 14/30 дней с запасом на репетицию и уточните, 164 ₽ — это за 7 дней или за месяц; включите автопродление |

**Цена 164 ₽** складывается как **99 ₽ (тариф 2 ГБ ОЗУ / 2 ядра) + 65 ₽ выделенный IP**.
Можно было бы взять `First 49 ₽ + IP = 114 ₽`, но я бы **оставил 2 ГБ**: на 512 МБ
Ubuntu 24 + nginx + certbot работают впритык, а переплата в 50 ₽ за спокойствие
в день защиты оправдана. 4 ГБ (159 ₽) и 8 ГБ (239 ₽) брать не надо.

Перед оплатой одним сообщением хостингу:
> Подтвердите, что выделенный IP — белый IPv4 (не NAT с пробросом портов), порты
> 80 и 443 открыты, доступ по SSH есть, и нет лимита на число соединений с одного IP.

### Установка (копировать целиком)

```bash
sudo apt update && sudo apt install -y nginx
sudo mkdir -p /var/www/akvachek
sudo cp /etc/nginx/sites-available/default /etc/nginx/sites-available/default.bak
sudo nano /etc/nginx/sites-available/default   # вставить конфиг из deploy/nginx.conf
sudo nginx -t && sudo systemctl reload nginx
sudo ufw allow 80/tcp && sudo ufw allow 443/tcp   # если ufw нет: sudo apt install -y ufw
curl -I http://<IP>/akvachek.html             # ждём 200
```

**Как положить файлы в `/var/www/akvachek/`** (любой из двух способов):

```bash
# 1) прямо на сервере — скачать готовый экран по уже рабочей ссылке
sudo curl -fL -o /var/www/akvachek/akvachek.html \
  'https://cdn.jsdelivr.net/gh/Igorr112323/Ivan100@bd402edc3abfe655dfd4d384da2e9ce45bac3daa/dist/akvachek.html'
sudo curl -fL -o /var/www/akvachek/index.html \
  'https://raw.githubusercontent.com/Igorr112323/Ivan100/bd402edc3abfe655dfd4d384da2e9ce45bac3daa/dist/index.html'

# 2) со своего компьютера, если репозиторий уже склонирован
git fetch origin arena/25308257-ivan100            # подтянуть ветку с готовым dist/
mkdir -p /tmp/akvachek-dist
git archive --format=tar origin/arena/25308257-ivan100 dist | tar -x -C /tmp/akvachek-dist --strip-components=1
scp /tmp/akvachek-dist/* root@<IP>:/var/www/akvachek/
```

Обязательно минимум `akvachek.html` + `index.html`; остальное (`questions.html`,
PDF, PNG) — по желанию, это раздатка для жюри.

Готовый конфиг лежит рядом: **`deploy/nginx.conf`**. В нём намеренно **нет**
`limit_conn`, `limit_req`, `auth_basic`, `deny`, `geo` — именно они создали бы то самое
«ограничение по подключениям с одного IP». `try_files` не трогает query string,
поэтому `?limit=70` работает без доп. настроек. `index akvachek.html` открывает
экран сразу с корня — **короткий адрес даёт более читаемый QR**, чем длинная ссылка
на jsDelivr с хешем коммита.

### HTTPS без покупки домена

QR с голым `http://1.2.3.4` scanners открывают, но часть телефонов покажет
предупреждение. Лучше HTTPS:

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 185.12.34.56.sslip.io    # подставить свой IP: DNS sslip.io уже резолвит его
```

`sslip.io` — бесплатный DNS-сервис вида `<IP>.sslip.io`, Let's Encrypt выпускает
сертификат через HTTP-01, нужен только открытый 80-й порт. Если есть свой домен —
ещё проще: A-запись на IP и `certbot --nginx -d ваш-домен.ru`.

### Проверка ровно под ваше требование

```bash
# 20 одновременных заходов с ОДНОГО IP, все должны вернуть 200
seq 1 20 | xargs -P20 -I{} curl -s -o /dev/null -w '%{http_code}\n' \
  'https://185.12.34.56.sslip.io/akvachek.html?limit=70' | sort | uniq -c
sudo tail -20 /var/log/nginx/error.log     # не должно быть 503 / 429 / limiting
grep -iE 'limit|429' /var/log/nginx/access.log | head
```

Дальше — с реального телефона по мобильному интернету: отсканировать QR,
проверить, что карта занимает экран, слайдер двигается, шторка открывается,
PDF и `questions.html` открываются. Это те же 14 тестов приёмки, но глазами.

## 3. Главная ловушка: QR уже напечатан на другой адрес

Если сайт переезжает на VPS, напечатанный QR, раздатка A4 и слайды **останутся
вести на jsDelivr** — жюри попадёт не на ваш сервер. Значит, надо перевыпустить
все три материала:

```bash
# 1. в web/site_url.py заменить SITE на новый короткий адрес, например
#    SITE = "https://185.12.34.56.sslip.io/"
python3 web/make_qr.py       # dist/qr.png            (нужен pip-пакет qrcode)
python3 web/handout.py       # /tmp/handout.html      (нужен Pillow)
python3 web/slides.py        # /tmp/slides.html
# 2. распечатать /tmp/handout.html и /tmp/slides.html в PDF браузером (A4 / 16:9)
# 3. заменить dist/handout.pdf, dist/slides.pdf и ПЕРЕПЕЧАТАТЬ раздатку
```

Пока нового адреса нет, QR трогать не надо. Если раздатка уже напечатана и
перепечатывать нельзя — оставьте QR на jsDelivr, а VPS держите как зеркало
и дайте его ссылку отдельно (на слайде/доске): для отчёта «сайт размещён на
арендованном сервере» этого достаточно, но по QR жюри всё равно уйдёт на CDN.

## 4. Чего НЕ делать

- Не поднимать `Dockerfile` / `docker-compose.yml` из проекта: это расчётный API,
  для готового экрана он лишний и только съест память младшего тарифа.
- Не включать `limit_conn addr`, `limit_req`, fail2ban, «режим под атакой»,
  geo-блок и базовую авторизацию — это ровно тот лимит по IP, которого вы боитесь.
- Не ставить Windows на 512 МБ / 1 ГБ ради статического HTML.
- Не брать срок аренды «впритык к защите» и не забыть про автопродление.
- Не менять `dist/akvachek.html` руками: все числа в нём из `content.json`.

## 5. Итоговый выбор

| Ситуация | Делать |
|---|---|
| Просто надо, чтобы жюри открыло сайт | **Ничего не арендовать.** Проверить текущую ссылку с телефона, включить Pages как запасной адрес. 0 ₽ |
| CDN на площадке недоступен / нужен адрес в РФ | VPS `First 49 ₽` на Ubuntu в РФ + nginx из `deploy/nginx.conf` + HTTPS через `sslip.io`, перевыпустить QR и раздатку |
| Аренда обязательна по условиям, но раздатку уже напечатали | VPS как зеркало + Pages/CDN как основной адрес по QR, новый адрес вывести на слайд отдельно |
