## 3. Что не удалось

1. **jsDelivr не проверен HTTP-запросом.** Из песочницы доступны только `github.com`,
   `api.github.com`, `registry.npmjs.org`, `pypi.org`; на `cdn.jsdelivr.net` и
   `raw.githubusercontent.com` curl возвращает 000. Проверено другое: каждый файл есть по
   указанному пути (GitHub API, код 200, размер совпадает с локальным байт в байт) и GitHub
   отдаёт **302** на `github.com/…/raw/<коммит>/dist/<файл>` против **404** на заведомо
   неверный путь. Фактические коды jsDelivr должен записать человек, открыв ссылки в инкогнито.
2. **GitHub Pages не опубликован** — сервис не включён, включить токен не может (403).
   Ссылок вида `igorr112323.github.io/Ivan100/…` сейчас не существует.
3. В файле `МАКЕТ_ЭКРАНА.md` (исторический документ дизайна, на сайте не используется)
   остались старые числа `3 131`, `2 720`, `11 860`. Не трогал: это не интерфейс, правка
   не входила в список. Сказать — уберу.
