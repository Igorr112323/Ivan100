## 4. Что не удалось

1. **jsDelivr не проверен HTTP-запросом.** Из песочницы доступны только `github.com`,
   `api.github.com`, `registry.npmjs.org`, `pypi.org`; на `cdn.jsdelivr.net` и
   `raw.githubusercontent.com` curl возвращает код 000 (хост недоступен). Проверено другое:
   каждый файл существует по указанному пути (GitHub API, код 200, размер совпадает с локальным
   файлом байт в байт) и GitHub отдаёт 302 на `github.com/.../raw/<коммит>/dist/<файл>` для
   правильного пути против 404 для заведомо неверного. Открыть ссылки в инкогнито и записать
   фактические коды должен человек.
2. **GitHub Pages не опубликован**: ответ API 404 — сервис не включён, а у токена нет прав
   на включение (POST /pages → 403 «Resource not accessible by integration»). Ссылки вида
   `igorr112323.github.io/Ivan100/…` сейчас не существуют.
3. **В `questions.html` ошибка в ответе на вопрос 1.** Строка «При −15 % выигрыш 6.49 % лежит
   внутри случайных перестановок… (медиана 1.56 %, 95-й процентиль 5.23 %)»: подставлены числа
   −30 % вместо −15 % (должно быть: 0,54 %; медиана 1,29 %; p95 3,87 %), и при этих числах
   фраза «лежит внутри» неверна. Причина — в `web/build_single.py` значения `{real}`, `{median}`,
   `{p95}` берутся из строки плацебо для −30 %. Правка — одна строка; по прямому запрету
   «ничего не дорабатывать» не правил. Файл куратору не пересылать до исправления.
4. Имена файлов — латиница, кириллицы нет; три `.md`-файла в корне репозитория остались с
   кириллическими именами, потому что они выдаются путём в репозитории, а не ссылкой на CDN.
